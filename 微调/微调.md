# 微调

## 什么是微调

**预训练（Pre-training）：**在大规模、多样化的无标注文本语料上（如网页、书籍、论文），通过自监督学习（如下一个词预测）训练模型的过程。目的是让模型学会通用的语言能力（语法、常识、推理逻辑）和世界知识。

**提示词工程（Prompt  Engineering）：**给通用大模型一个精心设计的提示词（背景，任务，约束，输出格式，Few-shot等），这种方式零成本、即时可用，但问题是：每次都要写长长的提示词、效果不稳定、容易被无关输入干扰、token 消耗大。

**微调（Fine-tuning）**。在预训练模型的基础上，使用特定任务的有标注数据集，进行进一步的参数更新训练。目的是将通用模型适配到特定领域或特定任务上。这样得到的模型，既能保留通用能力，又能在你的任务上表现出色，而且成本可控。

三种方式对比：

| 方式        | 成本     | 效果               | 适用场景             |
| ----------- | -------- | ------------------ | -------------------- |
| 预训练      | 极高     | 完全定制           | 创建新的基础模型     |
| Prompt 工程 | 几乎为零 | 不稳定，依赖提示词 | 简单任务，快速验证   |
| 微调        | 中等     | 稳定且专业         | 特定领域任务，产品化 |
