# 财务报销手册

## 常见费用标准

### 1. 住宿费

每人每晚不超过 **500 元**。

超过标准时，标记为「住宿费用超标」。

### 2. 餐饮费

* 普通工作餐：每人每次不超过 **100 元**
* 商务招待：每人每次不超过 **200 元**

商务招待需要说明招待事由、参与人员和客户或合作方名称。

### 3. 交通费

* 市内交通费：单次不超过 **200 元**
* 火车：原则上报销二等座
* 飞机：原则上报销经济舱

### 4. 采购费用

* 超过 **1000 元**：需要提前获得部门负责人审批
* 超过 **5000 元**：需要提供至少两家供应商的价格对比
